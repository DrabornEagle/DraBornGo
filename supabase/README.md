# DraBornGo Supabase schema boundary

DraBornGo v0.0.6 ile önceki oyunlaştırma ve uygulama-içi finans şemaları 2026-08-08 tarihinde üretim Supabase projesinden kaldırıldı. Eski SQL dosyaları yalnızca sürüm öncesi GitHub yedek dalında tutulur. Yeni şema değişiklikleri bu sürüm sınırından itibaren eklenmelidir.
